# SEO and metadata

## Current status

The repository does not yet contain a live web application or SEO implementation.

## Intended requirements

- Page titles and meta descriptions for property and dashboard views
- Open Graph metadata for public property profile pages
- Canonical URLs and clean route structure
- Semantic HTML for discoverability and accessibility
- Structured data for property listings when the marketplace is expanded later

## Notes

SEO is not the primary focus of the MVP owner ERP, but public-facing property pages and marketplace functionality will require metadata discipline once those flows are implemented.
