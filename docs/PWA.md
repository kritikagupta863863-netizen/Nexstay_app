# PWA notes

## Current status

The project plan includes PWA support in the TODO and product direction. There is no actual service worker or manifest in the repository yet.

## Intended PWA capabilities

- installable app experience
- online-only operation in MVP
- no offline data entry or synchronization
- update behavior for service worker versions
- mobile/tablet-first responsive web UX for property managers

## Design requirement

Because the target user base is mobile-heavy, the app should behave like an installable business tool rather than a pure website. MVP workflows require an active connection.
